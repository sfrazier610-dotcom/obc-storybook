# Wanderer's Quest art licenses

The default Vista look is an original shaded diorama. Shapes are drawn with canvas gradients (rounded shrubs, cliffs, cottages, chibi figures) and then shown through a low-resolution crisp upscale. Nothing is traced from a reference screenshot. No Nintendo characters, names, symbols, or assets are used.

## Original diorama art (default look)

- What: grass fields, earthen cliff bands, sandy paths, ponds, shrubs, rocks, pottery, fences, cottages, signs, lanterns, chests, the hero (book satchel), counselors, villagers, pets, and symptom clouds.
- Author: drawn for this game as original code in `vista.js`.
